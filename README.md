# KONOZ – كنوز

تطبيق أندرويد أصلي (Native Android) مكتوب بلغة **Kotlin** وواجهة **Jetpack Compose (Material 3)** بدعم كامل للغة العربية واتجاه الكتابة **RTL**، مصمم ليكون مساعداً ذكياً لتوثيق الصور والأوصاف النصية للرموز والنقوش ومقارنتها بقاعدة معرفية محلية قابلة للتطوير (**الدليل اليدوي لخرائط فكّ الرموز التكنيزية**).

- **معرّف الحزمة (`applicationId`)**: `com.konoz.app`
- **الحد الأدنى لنظام Android**: `minSdk = 24` (توافق كامل مع Android 10 وما بعده حتى Android 16)
- **الهوية البصرية**: ألوان داكنة مستوحاة من المخطوطات القديمة (البني الداكن، الذهبي المعتّق، الرمادي الحجري) مع خطوط عربية واضحة (`Amiri` و `Cairo`).

---

## المزايا الرئيسية

1. **الوضع الأول – تحليل الصور متعدد الوسائط**:
   - التقاط مباشر بالكاميرا عبر **CameraX** مع إطار توجيهي والتحكم بالفلاش.
   - اختيار صورة واحدة أو عدة صور للحالة نفسها عبر **Android Photo Picker** (دون الحاجة لصلاحيات تخزين واسعة).
   - قص تفاعلي وتحديد منطقة الرمز قبل التحليل + وصف اختياري.
   - تحليل من 5 مراحل (الفحص البصري ← السياق ← مطابقة الدليل ← التحليل المنطقي ← التقرير المفصل).
2. **الوضع الثاني – التحليل بالوصف النصي ومحادثة المتابعة**:
   - استخراج فوري للرموز مع الحفاظ على التراكيب العددية (`41`، `1.4`، `6 + 9`، الأرقام من 4 خانات فأكثر) دون تفكيك عشوائي.
   - محادثة متابعة لإعادة تقييم التفسير عند إضافة معلومات جديدة مع الحفاظ على كامل السياق السابق.
3. **قاعدة المعرفة المحلية (Room Database – إدارة الدليل)**:
   - تحتوي على جميع أقسام الدليل اليدوي (الحروف، الأرقام والتراكيب العددية، الرموز الخاصة، الرموز الدينية، الأسماء، التركيبات، الرصد والأسلاك، المناظير، التثبيت، الأشجار والصخور، علامات الخطر، الألوان والرسومات، القواعد العامة).
   - إضافة رموز جديدة، تعديل المعاني، إضافة معانٍ بديلة مع المصدر والسياق، تعطيل القواعد دون حذفها، والبحث الفوري.
   - **تصدير واستيراد JSON** بدمج غير تدميري (لا يحذف القواعد القديمة).
4. **نظام التقارير الاحترافي (9 أقسام)**:
   - فصل صريح بين **الملاحظة الفعلية** و**الاستنتاج** و**الفرضية**.
   - إدارة التعارضات (مثل حرف `S` بين طريق وأموال ورقية) والتنبيه عند تعذر الترجيح.
   - مستويات ثقة منفصلة بالكلمات دون نسب مئوية توحي بدقة علمية غير موجودة.
5. **سجل التحليلات والمفضلة (يعمل دون إنترنت)**:
   - حفظ التقارير والصور والملاحظات الشخصية ومحادثات المتابعة محلياً في **Room**.
6. **طبقة الذكاء الاصطناعي القابلة للتبديل (`AIService`)**:
   - الافتراضي: **Firebase AI Logic (Gemini Vision)** مع حماية **Firebase App Check** دون تضمين أي مفتاح API في الكود.
   - خيار بديل من الإعدادات: **خادم وسيط مخصص (Custom HTTPS Proxy)** لتشغيل مزود خارجي بأمان خارج ملف APK.

## الأمان والمسؤولية

- التطبيق مخصص للتوثيق ودراسة الفرضيات الواردة في دليل المستخدم فقط، ولا يُعد مرجعاً أثرياً علمياً مثبتاً.
- لا يقدم التطبيق إحداثيات دفائن أو مسافات أو توجيهات حفر أو طرق فتح القبور أو تعطيل الألغام.
- عند رصد مؤشرات خطر محتملة (مثل الأسلاك، المسامير المشبوهة، الفرشات القبايلية، المثلث، `#`، الهيكل العظمي)، يُوقف التحليل الميداني ويُعرض تحذير فوري للابتعاد والتواصل مع الجهات المختصة.

## البناء والاختبار عبر GitHub Actions

يتضمن المشروع ملف `.github/workflows/android-build.yml` الذي يقوم تلقائياً بـ:
1. تشغيل اختبارات الوحدة وRobolectric (`:app:testDebugUnitTest`) التي تغطي الحالات الـ 12 المطلوبة.
2. بناء وتصدير ملف **`app-debug.apk`** كـ Artifact جاهز للتنزيل والتثبيت.
3. دعم بناء نسخة **Release** موقّعة بتوقيع ثابت عند إضافة أسرار التوقيع (`KEYSTORE_BASE64`, `STORE_PASSWORD`, `KEY_PASSWORD`) في إعدادات مستودع GitHub دون رفع المفتاح إلى الكود العام.
